# FUNDY v2.6 Android

Project Android WebView siap build via GitHub Actions.

1. Upload seluruh isi folder ini ke root repository GitHub.
2. Pastikan branch bernama `main`.
3. Buka tab Actions > Build FUNDY APK > Run workflow.
4. Setelah selesai, buka run tersebut dan download artifact `FUNDY-v2.6-debug`.
5. Ekstrak ZIP artifact untuk mendapatkan `app-debug.apk`.

Backup JSON/CSV dari aplikasi Android disimpan ke folder Download/FUNDY.
